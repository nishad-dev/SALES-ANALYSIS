🏠📊 Sales Analysis Dashboard – Home Appliances
📌 Project Overview

This project showcases an interactive Sales Analysis Dashboard built in Microsoft Excel to analyze the performance of home appliance products across different regions and categories.

The dashboard provides a clear, visual representation of sales, quantity distribution, and return status, helping stakeholders make informed business decisions.

🎯 Key Objectives
Analyze sales performance across regions
Track product category demand
Understand return patterns
Identify top-performing regions and categories
Deliver interactive insights using Excel dashboarding techniques
🛠️ Tools & Skills Used
Microsoft Excel
Pivot Tables & Pivot Charts
Slicers (for interactivity)
Data Cleaning & Transformation
Conditional Formatting
Data Analysis
Trend Analysis
Comparative Analysis
KPI Tracking
